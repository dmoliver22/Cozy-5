# Neon Reverie collection download

`neon-reverie-complete.zip` contains all ten 1254 × 1254 PFP artworks, individual NFT metadata, a collection avatar and banner, an offline gallery, a browser-based IPFS metadata helper, a locally tested Ethereum ERC-721 contract, and creation instructions.

On GitHub, open the ZIP file and use **Download raw file** to save it to your computer. Extract it and open `neon-reverie/gallery.html`. Read `neon-reverie/START_HERE.md` for hosting, minting, and OpenSea steps.

The artworks are prepared; no NFTs have been minted or listed. Minting requires your wallet, hosted artwork/metadata, and Ethereum gas.
